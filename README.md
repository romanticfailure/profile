# romanticfailure profile

Минималистичный чёрно-белый персональный сайт на Vite.

## Запуск локально

1. Установи Node.js (LTS).
2. Открой папку проекта в терминале.
3. Выполни:

```bash
npm install
npm run dev
```

4. Открой адрес, который покажет Vite (обычно `http://localhost:5173/`).

## Что уже сделано

- Экран `click to enter...` с анимированным звёздным небом.
- Переход на профиль по нажатию в любом месте стартового экрана.
- Терминал с печатью текста, паузой 10 секунд, мерцанием и повтором.
- Надпись `@romanticfailure profile`.
- Панель регулировки громкости (сам плеер пока без аудио).
- Раздел `My info`.
- Копирование Discord `opensourceworker` с уведомлением `Copied`.
- Заглушки для GitHub и guns.lol до добавления ссылок.
- Адаптация под мобильные экраны.

## Добавление музыки и ссылок

Музыку можно будет подключить позже в `index.html` и `src/main.js`.
Ссылки GitHub и guns.lol добавим в карточки в `index.html`, когда они будут готовы.
